# ADR-0003：.env 每次调用现读，不做缓存

状态：accepted（2026-08）

## 背景

`spawnSpec` 每次 pwsh 调用都执行，`.env` 读取可以缓存（mtime 比较）也可以现读 `readFileSync`。

## 备选

| 方案 | 结论 |
|------|------|
| mtime 缓存 | 省 IO，但引入缓存失效逻辑；改 `.env` 依赖 mtime 判定 |
| 每次现读 | 逻辑最简单，天然即时生效 |

## 决策

每次现读。

## 后果

- 改 `.env` **立即生效无需重启**——成为插件的核心卖点之一
- workspace `.env` 通常几十行，SSD 上小文件读开销可忽略
- 若将来 `.env` 显著变大再加 mtime 缓存，接口不变
